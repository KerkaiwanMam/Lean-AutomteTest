ShopLab REST API

Base URL: /api · Machine-readable contract: /api/openapi.json (OpenAPI 3.0 — import it into Postman, Insomnia or Swagger UI).

Quick start

# 1) reset data to a known state (non-production only)
curl -X POST http://localhost:3000/api/test/reset

# 2) login and keep the token
curl -X POST http://localhost:3000/api/auth/login -H "Content-Type: application/json" \
     -d '{"username":"customer","password":"Passw0rd!"}'

# 3) call a protected endpoint
curl http://localhost:3000/api/cart -H "Authorization: Bearer <token>"

# 4) turn on bug mode / latency (chaos)
curl -X POST http://localhost:3000/api/test/config -H "Content-Type: application/json" \
     -d '{"bugMode":true,"latencyMs":500}'

Error format

{ "error": { "code": "VALIDATION_ERROR", "message": "Invalid input", "details": { "email": "Email is invalid" } } }
